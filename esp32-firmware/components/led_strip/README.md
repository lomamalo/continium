Vendored copy of `espressif/led_strip` (v3.0.3, RMT + SPI backends), from
https://github.com/espressif/idf-extra-components/tree/master/led_strip
(Apache-2.0, see LICENSE).

Vendored directly instead of pulled via the ESP-IDF Component Manager so
this project builds fully offline once ESP-IDF itself is installed --
consistent with the rest of this project's local-first approach. To
update, replace this directory with a fresh checkout of the same path.
