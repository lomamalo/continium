CONTINIUM

Copié sur le PC, continué sur le téléphone. Presse-papier, liens, vidéos et fichiers traversent la passerelle — sans cloud, sans compte, chez toi.

Télécharger l'app Installer sur Linux

Tout ce qui passe, continue

L'app reçoit en quelques secondes ce que tu copies ou envoies depuis le PC, catégorisé automatiquement.

Presse-papier universel

Ctrl+C sur le PC, collé dans le presse-papier du téléphone. Le texte copié arrive sur l'app en direct, prêt à être recopié ou renvoyé.

Liens & vidéos

Un lien YouTube copié devient une carte vidéo avec titre et position de lecture, à ouvrir sur le téléphone ou continuer sur le PC.

Fichiers & renvoi

Les fichiers poussés depuis le PC s'éditent dans l'app, et le résultat est réécrit dans le fichier d'origine côté PC.

Découverte automatique

L'app trouve le daemon sur le réseau sans rien saisir : UDP broadcast, une connexion mémorisée, reconnexion automatique.

Boîtier ESP32 autonome

En veille entre deux cycles (~10 min) sur batterie, LED fixe quand il est branché. Son état et sa batterie s'affichent en direct dans l'app.

Extension navigateur

Un bouton dans Firefox pour envoyer la page courante vers le téléphone : titre, URL, position de lecture — en un clic.

Trois pièces, une seule continuité

Chaque élément capturé traverse le pipeline en quelques millisecondes, du presse-papier jusqu'à l'écran du téléphone.

Installation sur PC Linux

Une seule commande : elle installe le daemon en service systemd (presse-papier + serveur web + boitier) et pose un raccourci sur le Bureau. L'app s'ouvre dans le navigateur — aucune dépendance, aucune compilation, toutes distros.

$ curl -fsSL https://raw.githubusercontent.com/lomamalo/continium/main/docs/install-pc.sh | bash

Pour retrouver l'URL de l'app (sur ce PC ou sur le réseau) : curl -fsSL …/install-pc.sh | bash -s - -ip

Voir le contenu du script install-pc.sh 
#!/usr/bin/env bash
# Continium — installateur PC : daemon + service + raccourci + extension
set -euo pipefail
BASE="https://github.com/lomamalo/continium/releases/latest/download"
BIN_DIR="$HOME/.local/bin"
APP_DIR="$HOME/.local/share/continium"
SERVICE_DIR="$HOME/.config/systemd/user"
URL_LOCAL="http://127.0.0.1:8081"

# 1. Daemon Rust (service systemd utilisateur)
curl -fsSL "$BASE/passerelle-daemon" -o "$BIN_DIR/passerelle-daemon"
chmod +x "$BIN_DIR/passerelle-daemon"
# ... service systemd genere puis active :
# systemctl --user enable --now passerelle-daemon

# 2. Raccourci sur le Bureau vers l'app web (navigateur)
cat > "$(xdg-user-dir DESKTOP)/continium.desktop" <<EOF
[Desktop Entry]
Type=Application
Name=Continium
Exec=xdg-open $URL_LOCAL
Icon=$APP_DIR/continium.png
Terminal=false
EOF

# 3. Extension Firefox (installation manuelle en un clic)
curl -fsSL "$BASE/passerelle.xpi" -o "$EXT_DIR/passerelle.xpi"

# Option -ip : affiche l'URL sans reinstaller :
# curl -fsSL …/install-pc.sh | bash -s - -ip
loginctl enable-linger "$USER" 2>/dev/null || true

echo "==> Continium installé. Ouvre : http://127.0.0.1:8081"
